## Changes driven by this test

CRLF/CR/LF and sends explicit Enter keys between text chunks. Five focused unit tests
cover line handling; the corrected multiline entry compiled in the actual IDE.
Multiline input is for confirmed multiline editors only: Enter can submit a dialog.

An edited variable name appended to `NewVar1`; the actual saved name was
`NewVar1iSmokeValue`. The test used that exact name and documented the failed intended
replacement rather than reporting a clean rename. Tool guides now require checking
cell edit mode and the full committed name.

Ctrl+S saved only the active worksheet. Tool guides now require observed Save All
and disk read-back before whole-project verification. Immediately returned screenshots
sometimes showed old state; follow-up observation was required before repeating input.

The optional desktop-control HTTP transport requires a bearer token and binds only
to loopback. A request without authentication returned 401 in the live test.
